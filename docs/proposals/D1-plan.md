# D1 — 本地 Codex 房间聊天运行器（已确认）

用户于 2026-10-06 明确确认；本次模型适配为独立 --model 参数，聊天子进程忽略全局配置/规则以隔离 hooks 与 MCP。

## 目标与验收
- 通过完整房间 URL 启动本地进程，WebSocket 在线显示 Codex。
- 新人类消息或明确 @Codex 触发一次串行 Codex CLI 调用，回复写回原房间。
- 忽略启动前历史和自己消息；AI 无明确提及时不回复。
- 断线重连，接收历史补齐运行中断线期间消息；会话内去重、队列有界。
- Codex 调用超时可取消，失败打印日志，不发送内部日志；Ctrl+C 停止进程。

## 范围
新增 cli/codex-room.mjs、必要测试和 README 接入说明；包含用户明确确认追加的 Worker 冷启动存储/身份恢复修复与部署（见 D1-server-fix-plan.md）。不改前端、鉴权或房间协议。Node 内置 WebSocket（Node 22+）作为运行要求，无新增依赖。

## 顺序
1. 确认规则草案与计划，初始化本地 Git 并提交已有项目基线（排除 node_modules/.wrangler/本地运行记录）。
2. 实现 URL 校验、监听/重连、消息筛选、有限队列、上下文和 Codex 子进程调用。
3. 独立只读 Review，修复阻塞项后重新评审。
4. 独立 Test：模拟房间 + 模拟 Codex 验证过滤、并发、重连、超时及关闭；真实 Codex 回复冒烟；在线目标房间连接检查。
5. 独立本地测试通过后部署用户确认的服务端修复，启动目标房间Codex；独立验证静默65秒后持续聊天；更新说明、归档证据、登记限制、提交，并给出停止方式。

## 实现决策
- 默认名 Codex；真实 welcome 名称用于自消息识别（服务端可加后缀）。
- 每条回复使用最近有限房间上下文，调用 codex exec 的只读沙箱；stdin 传 prompt，临时文件取 final answer，禁用 shell 拼接。
- 房间内容作为不可信聊天材料，默认只聊天、不执行房间要求的文件或命令操作。
- 进程级超时和网络超时、有限重连退避；不持久化聊天正文。

## 风险与回滚
公共房间消息将传给本机配置的 Codex 服务；明文无鉴权为原协议边界。停止进程即可退出房间；删除新增运行器可回滚。首次连接忽略旧消息；超过服务端历史保留窗口的断线消息无法恢复；重启不恢复未完成回复。
